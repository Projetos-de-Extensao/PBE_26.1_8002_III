# Ementa do Curso — Engenharia de Software (Ibmec)

## 1. Fundamentos da Computação
- Lógica de Programação e Algoritmos
- Estruturas de Dados (listas, filas, pilhas, árvores, grafos, tabelas hash)
- Teoria da Computação e Linguagens Formais
- Arquitetura e Organização de Computadores
- Sistemas Operacionais

## 2. Programação e Desenvolvimento
- Programação Orientada a Objetos (Java, Python, C#)
- Programação Funcional
- Programação Web (HTML, CSS, JavaScript, TypeScript)
- Desenvolvimento Mobile (Android, iOS, React Native, Flutter)
- Frameworks e Bibliotecas (React, Angular, Vue, Django, Spring Boot, .NET)

## 3. Engenharia de Software
- Processos de Software (RUP, Scrum, Kanban, XP)
- Engenharia de Requisitos
- Modelagem e Projeto de Software (UML, Design Patterns)
- Arquitetura de Software (Monolítica, Microsserviços, Serverless, Event-Driven)
- Qualidade de Software e Testes (Unitários, Integração, End-to-End, TDD, BDD)
- DevOps, CI/CD e Infraestrutura como Código
- Gestão de Configuração e Controle de Versão (Git)

## 4. Banco de Dados
- Modelagem de Dados (Relacional e NoSQL)
- SQL e consultas avançadas
- Sistemas Gerenciadores de Banco de Dados (PostgreSQL, MySQL, MongoDB, Redis)
- Data Warehousing e Business Intelligence

## 5. Redes e Sistemas Distribuídos
- Redes de Computadores e Protocolos (TCP/IP, HTTP, WebSocket)
- Computação em Nuvem (AWS, Azure, GCP)
- Sistemas Distribuídos e Microsserviços
- APIs RESTful e GraphQL

## 6. Segurança da Informação
- Criptografia e Certificados Digitais
- Segurança de Aplicações Web (OWASP Top 10)
- Autenticação e Autorização (OAuth2, JWT)
- LGPD e Proteção de Dados Pessoais

## 7. Inteligência Artificial e Ciência de Dados
- Introdução à Inteligência Artificial
- Machine Learning e Deep Learning
- Processamento de Linguagem Natural (NLP)
- Análise e Visualização de Dados (Pandas, Matplotlib, Power BI)
- Estatística e Probabilidade aplicadas

## 8. Gestão e Negócios
- Empreendedorismo e Inovação Tecnológica
- Gestão de Projetos de Software (PMI, Scrum Master)
- Metodologias Ágeis
- Produto Digital (Product Management, UX/UI Design)
- Comunicação e Trabalho em Equipe

## 9. Matemática e Ciências Exatas
- Cálculo Diferencial e Integral
- Álgebra Linear
- Matemática Discreta
- Lógica Matemática

## 10. Ética e Sociedade
- Ética Profissional em Tecnologia
- Responsabilidade Social e Sustentabilidade
- Impacto da Tecnologia na Sociedade
- Acessibilidade Digital
